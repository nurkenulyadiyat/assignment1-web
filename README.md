# Assignment #1 — HTML & CSS Basics

Personal practice project for the Web Technologies 1 (Front End) course at Astana IT University. Four small pages built with plain HTML and CSS, each focused on a different set of fundamentals.

## Live site

Published via GitHub Pages: `https://nurkenulyadiyat.github.io/assignment1-web/`

## Pages

| Task | File | Focus |
|---|---|---|
| Task 1 | `index.html` | Personal page — HTML basics, element/class/ID selectors, box model |
| Task 2 | `layout.html` | Page layout using only `<div>` + float/position (no Flexbox/Grid) |
| Task 3 | `exercise1/index.html` | Tribute page for Linus Torvalds — Google Fonts, styled container/image/lists |
| Task 4 | `table-form.html` | Styled student grades table + feedback form |

A shared navbar at the top of every page links between all four.

## How to view locally

Clone the repo and open `index.html` in a browser, or serve the folder with a local server (e.g. the VS Code "Live Server" extension) and navigate from there.
