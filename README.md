# Assignment #1 — HTML & CSS Basics

Practice project for the Web Technologies 1 (Front End) course at Astana IT University. Five tasks built with plain HTML and CSS, each focused on a different set of fundamentals. Tasks 1–4 were done individually; Task 5 is the midterm project planning stage.

## Live site

Published via GitHub Pages: `https://nurkenulyadiyat.github.io/assignment1-web/`

## Pages

| Task | File | Focus |
|---|---|---|
| Task 1 | `index.html` | Personal page — HTML basics, element/class/ID selectors, box model |
| Task 2 | `layout.html` | Page layout using only `<div>` + float/position (no Flexbox/Grid) |
| Task 3 | `exercise1/index.html` | Tribute page for Linus Torvalds — Google Fonts, styled container/image/lists |
| Task 4 | `table-form.html` | Styled student grades table + feedback form |
| Task 5 | `wireframes/wireframes.html` | Midterm project — topic, sitemap and wireframes |

A shared navbar at the top of every page links between all five.

## Task 5 — Midterm project

**Topic:** SHOQAN — an online store of classic men's clothing (suits, shirts, coats, trousers and accessories).

SHOQAN is aimed at men aged 25–50 — office employees, businessmen and grooms — who need formal and business wear. The website lets a customer browse the catalogue, filter items by category, size and price, open a detailed product page and place an order, and it also presents the store itself through an about section and a contact form.

The project has five pages — Home, Catalog, Product, Cart / Checkout, About & Contact — each with a consistent header, main content area and footer. Wireframes were made in Balsamiq and are stored in `wireframes/` as PNG images:

| File | Page |
|---|---|
| `00_sitemap.png` | Navigation structure |
| `01_home.png` | Home |
| `02_catalog.png` | Catalog |
| `03_product.png` | Product |
| `04_cart_checkout.png` | Cart / Checkout |
| `05_about_contact.png` | About & Contact |

`wireframes/wireframes.html` shows all of them on one page together with the project description.
