Linus Torvalds

Born 28 December 1969

About Linus Torvalds

Linus Torvalds (born 1969 in Helsinki, Finland) is a software engineer best known as the creator of the Linux kernel, the open-source operating system core that now runs the majority of the world's servers, smartphones (through Android), and supercomputers. In 2005 he also created Git, the version-control system used by virtually every software team today. He still oversees Linux kernel development through the Linux Foundation.

Key life events

  1. 1969 – Born in Helsinki, Finland.
  2. 1991 – Announced and released the first Linux kernel (v0.01).
  3. 1997 – Joined Transmeta to work on low-power x86 processors.
  4. 2005 – Created Git in about ten days to replace BitKeeper for kernel development.
  5. 2011 – Awarded the Millennium Technology Prize for creating Linux.

Key contributions

  • The Linux kernel — the open-source core behind countless servers, phones, and devices
  • Git — the version control system almost every developer uses today
  • Popularizing the open-source, collaborative development model
  • Ongoing leadership of Linux kernel development via the Linux Foundation

Learn more about his work: kernel.org and git-scm.com.
